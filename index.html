VTStudio is a Windows audio recording and editing application designed to make working with audio clips straightforward.

↓ Install VTStudio
Windows 10/11 • Free development preview

What you can do

🎤 Record audio

Capture recordings directly from your microphone.

✂ Edit clips

Cut, copy, paste, split, and organize audio.

🎵 Work with waveforms

View and navigate audio visually while editing.

↻ Automatic updates

Receive new versions through the built-in update system.

How to install

  1. Click Install VTStudio above.
  2. Open the downloaded setup.exe file.
  3. Follow the Windows installation prompts.
  4. Launch VTStudio from the Start menu or its shortcut.
Development preview: VTStudio is currently distributed without a trusted publisher certificate. Windows may display an Unknown Publisher or SmartScreen warning. Install only if you trust the source.
